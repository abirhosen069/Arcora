# Deploy ArcOra Online (No Local Dev Required)

This guide deploys the ArcOra backend to **Render** with managed PostgreSQL. The Android app is preconfigured to call `https://arcora-api.onrender.com/` (update `arcora/gradle.properties` after you choose a different service name).

## Prerequisites

- [Render](https://render.com) account (free tier works for testnet MVP)
- [GitHub](https://github.com) repo with this project pushed
- Arc Testnet USDC for the server relayer wallet ([Circle faucet](https://faucet.circle.com))

## 1. Push to GitHub

```bash
git init
git add .
git commit -m "ArcOra production deployment setup"
git remote add origin https://github.com/YOUR_USER/arcora.git
git push -u origin main
```

## 2. Deploy with Render Blueprint

1. Open [Render Dashboard](https://dashboard.render.com/) → **New** → **Blueprint**
2. Connect your GitHub repo
3. Render reads [`render.yaml`](render.yaml) at the repo root and creates:
   - **arcora-api** — Docker web service (NestJS backend)
   - **arcora-db** — PostgreSQL database
4. When prompted, set the secret **`RELAYER_PRIVATE_KEY`**:
   - Generate: `openssl rand -hex 32` → prefix with `0x`
   - Fund the relayer address with Arc Testnet USDC (check `/health` for `relayerAddress` after deploy)
5. Click **Apply** and wait for the first deploy (~5–10 min)

## 3. Verify Backend

```bash
curl https://arcora-api.onrender.com/health
```

Expected:

```json
{
  "status": "ok",
  "database": "ok",
  "transactionExecutionReady": true,
  "relayerAddress": "0x..."
}
```

If `transactionExecutionReady` is `false`, set `RELAYER_PRIVATE_KEY` in Render → arcora-api → Environment and redeploy.

## 4. Fund the Relayer

1. Copy `relayerAddress` from `/health`
2. Send Arc Testnet USDC to that address via [Circle faucet](https://faucet.circle.com) or another testnet wallet
3. Users receive USDC from this relay after biometric approval (testnet custodial relay mode)

## 5. Point Android at Your API

If your Render service URL differs from `arcora-api.onrender.com`, update:

```properties
# arcora/gradle.properties
ARCORA_API_BASE_URL=https://YOUR-SERVICE.onrender.com/
```

Rebuild the APK:

```bash
cd arcora
./gradlew :app:assembleRelease
```

APK output: `arcora/app/build/outputs/apk/release/app-release-unsigned.apk`

## 6. Environment Variables (Render)

| Variable | Required | Notes |
|----------|----------|-------|
| `DATABASE_URL` | Auto | From Render PostgreSQL |
| `JWT_SECRET` | Auto | Generated by blueprint |
| `RELAYER_PRIVATE_KEY` | **Yes** | `0x` + 64 hex chars; fund with testnet USDC |
| `ARC_RPC_URL` | Set | `https://rpc.testnet.arc.network` |
| `ARC_USDC_ADDRESS` | Set | `0x3600000000000000000000000000000000000000` |
| `CORS_ORIGINS` | Set | `*` for mobile-only MVP |

Optional later: `CIRCLE_KIT_KEY`, `GOOGLE_ANDROID_CLIENT_ID`, `SENTRY_DSN`.

## 7. CI/CD

GitHub Actions in [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) validates backend build and Android assemble on every push.

## Architecture

```
Android App (HTTPS)
    ↓  Authorization: Bearer <session>
Render Web Service (Docker)
    ↓  Prisma migrate deploy on start
PostgreSQL (managed)
    ↓  viem ERC20 transfer
Arc Testnet RPC
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `database: error` on `/health` | Check `DATABASE_URL`; ensure migrate ran (view deploy logs) |
| Payments fail with `execution_not_configured` | Set and fund `RELAYER_PRIVATE_KEY` |
| Android network errors | Confirm `ARCORA_API_BASE_URL` matches deployed HTTPS URL |
| Render cold start (~30s) | Upgrade to paid plan or accept free-tier spin-down |

## Security Notes

- **Testnet only** — relayer holds testnet USDC, not production funds
- Never commit `.env`, keystore files, or private keys
- Replace `CORS_ORIGINS=*` before public web clients
